## How does each paper define the prior over expressions and the prior over constants?

### Takeaway
Structure priors fall into five types: operator counts fitted to a corpus (G20), a uniform code of k·log(n) nats for a tree of k nodes (ESR), a parent-to-children n-gram language model (PSR), a tree-growth process with depth-dependent stopping (J19), and a flat prior (BL25). Priors over constants are almost never stated explicitly: they are either assumed smooth and absorbed into BIC, improper uniform and repaired with the fractional Bayes factor, or replaced by a code length set by the Fisher information.

### Cited Findings

**Corpus-count prior (Bayesian machine scientist)**
- The prior is the maximum-entropy distribution that reproduces, per expression, the mean count of each operation and the mean of its square in a corpus: p(m) ∝ exp[ Σ_o ( −α_o n_o(m) − β_o n_o(m)² ) ], with α_o, β_o ≥ 0 (FF23 Methods, Eq. 10; same form in GS25 Eq. 13 and G20 Materials and Methods). — [FF23](https://arxiv.org/abs/2204.02704)
- The corpus is 4080 expressions parsed from Wikipedia's "List of scientific equations named after people"; e.g. the mean number of sums per expression is 0.312 and the mean of its square 0.731 (G20, section "Estimation of prior probabilities", Fig. 2, Materials and Methods). — [G20](https://arxiv.org/abs/2004.12157)
- α_o and β_o are fitted by repeatedly sampling 1 to 10 million expressions from the current prior with the MCMC and nudging each parameter by the relative mismatch to the corpus target; a β_o that goes negative is set to 0 (G20, "Fitting of prior hyperparameters"). Tree size is capped at 50 nodes "to avoid problems with improper priors" (G20, "MCMC moves"). — [G20](https://arxiv.org/abs/2004.12157)
- A uniform prior over expressions is rejected: with a finite data set and a very large model space "one can always find a very complex model that fits the data arbitrarily well even with very few parameters" ("structural overfitting"); the prior acts as the regulariser (G20, same section). GS25 adds that ignoring the prior means complex models are favoured a priori because there are exponentially more of them (GS25 Sec. 3.1). — [G20](https://arxiv.org/abs/2004.12157); [GS25](https://arxiv.org/abs/2507.19540)
- The most probable models under this prior are those with no operation at all (m = const or m = x1), called "trivial" models (FF23 Methods, "Prior over models"). — [FF23](https://arxiv.org/abs/2204.02704)
- Fitted values, read from the code repository rather than the paper (the paper's Tables S3 and S4 could not be opened). File for 2 variables and 5 parameters, α_o in nats per occurrence: pow2 3.55, − 3.58, × 4.03, / 5.12, sqrt 5.17, log 5.18, exp 5.20, + 5.30, cos 5.91, ** 6.05, pow3 6.39, sin 6.44, abs 6.83, sinh 7.44, cosh 7.73, tanh 8.06, tan 8.15, factorial 8.21. β_o is non-zero only for × (0.055), / (0.052) and the rare hyperbolic/tan operators (0.28 to 1.08). For 5 variables and 5 parameters the values are similar (× 4.38, + 5.59, / 5.49, pow2 3.53, exp 5.11, sin 6.34). A separate file exists for each (number of variables, number of parameters) pair. — [BMS repository, branch no_degeneracy, Prior/](https://bitbucket.org/rguimera/machine-scientist/src/no_degeneracy/Prior/)
- Corpus totals in the same repository: × 2774, + 1271, / 1146, ** 652, pow2 547, − 520, log 132, sqrt 130, exp 129, cos 65, sin 39, pow3 38 occurrences over the 4080 expressions. — [BMS repository, Process-Formulas/data](https://bitbucket.org/rguimera/machine-scientist/src/master/Process-Formulas/data/)
- Prior over constants in G20/FF23/GS25: not specified. The Laplace/BIC step only assumes p(θ|m) is "smooth" near the maximum-likelihood point so that it can be treated as constant (FF23 after Eq. 4; GS25 Sec. 2). — [FF23](https://arxiv.org/abs/2204.02704)

**Uniform operator code (ESR)**
- The structure cost is k·log(n) nats for a tree with k nodes built from n distinct operators (parameters and variables count as operators); it "treats all operators equally" and is described as a uniform prior over function space given the operator set (ESR Sec. III before Eq. 2, footnote 3, and Sec. V-C). — [ESR](https://arxiv.org/abs/2211.11461)
- PSR writes out the prior that this code implies: −log P(f) = k·log n + Σ log c_α + (p/2)·log(2π ν_p), where the last term is about 0.87 nats per parameter for a rectangular quantisation lattice (0.69 to 0.87 for an optimal lattice) (PSR Eq. 7 and text after). — [PSR](https://arxiv.org/abs/2304.06333)
- Constants in ESR have no prior; each real parameter is coded as an integer multiple of a precision Δ_i, costing log(|θ_i|/Δ_i) + log 2 nats (sign bit) (ESR Sec. III before Eq. 2). PSR identifies this as Rissanen's universal code for the integers applied to θ/Δ (PSR after Eq. 7). — [ESR](https://arxiv.org/abs/2211.11461); [PSR](https://arxiv.org/abs/2304.06333)

**n-gram language-model prior (PSR)**
- Tree probability is factorised over sibling sets conditioned on up to n−1 direct ancestors: P(T) ≈ Π_i Π_j P(s_i^j | a_{i−1}^{ij}, …, a_{i−(n−1)}^{ij}) (PSR Eq. 13). Conditional probabilities come from a Katz back-off model with Good–Turing discounting (PSR Eqs. 14–16), so unseen combinations get non-zero probability. For a binary node the left child is drawn given ancestors and the right child given the left child. — [PSR](https://arxiv.org/abs/2304.06333)
- Training set: 161 equations (100 Feynman database, 20 "bonus", 41 from Wikipedia's named-equations list). n = 2 (condition on the parent only) was chosen because n = 1 vs n = 2 priors differ strongly while n = 2 vs n = 3 differ little (PSR Sec. 2.4.2, Fig. 1). — [PSR](https://arxiv.org/abs/2304.06333)
- Motivation: a count-only prior gives sin(sin(x0 + x1)) and sin(x0) + sin(x1) the same probability (PSR Sec. 1). — [PSR](https://arxiv.org/abs/2304.06333)
- Prior over constants in PSR: improper uniform, made usable by the fractional Bayes factor with training fraction b = N^(−1/2) (PSR Sec. 2.3, Eqs. 8–11). Uniform priors with finite bounds are rejected because the evidence scales with the bound width, differently for models with different numbers of parameters; PSR states that the ranking in G20 can be changed by changing the uniform bounds (PSR Sec. 2.3). Jeffreys and reference priors are rejected as usually improper. — [PSR](https://arxiv.org/abs/2304.06333)

**Tree-growth priors (J19 and the forest methods in the survey)**
- A node at depth d is non-terminal with probability α(1+d)^(−β); a non-terminal node takes an operator from a weight vector (default uniform, 1/6 each over exp, lt, inv, neg, +, ×); a terminal takes a feature uniformly. The model is y = β0 + Σ_{i=1..K} β_i g_i(x) + ε with K fixed in advance (J19, "Priors on Tree Representations" and "Linear Mixture of Simpler Trees"). — [J19](https://arxiv.org/abs/1910.08892)
- Constants in J19 live only in the linear-transformation operator lt(x) = a·x + b, with a ~ N(1, σ_a²), b ~ N(0, σ_b²) and inverse-gamma hyperpriors on the variances; the noise variance has an inverse-gamma prior; the outer coefficients β_i are fitted by ordinary least squares and not sampled (J19, "Prior of lt() Parameters"). — [J19](https://arxiv.org/abs/1910.08892)
- HierBOSSS (Roy et al., as described in RF26) uses the same depth rule with Dirichlet-distributed operator and feature weights, and a normal-inverse-gamma prior on the linear coefficients and noise variance, which makes the marginal likelihood closed-form (RF26 Sec. III-B6). RF26 could not reproduce its reported recoveries. — [RF26](https://arxiv.org/abs/2606.06567)

**Flat and other priors**
- BL25 uses π(M) ∝ 1 (in practice the distribution of the random expression generator) and an improper uniform prior on constants (BL25 Sec. 1 and 1.1). B22 does the same. — [BL25](https://arxiv.org/abs/2512.10849); [B22](https://ntrs.nasa.gov/api/citations/20220001900/downloads/smcbingo_gecco22.pdf)
- H25 estimates conditional categorical distributions P*(s_i | siblings, parent, level) from normalised operator counts over expressions from 10,000 arXiv papers per domain (physics, biology, chemistry, engineering) (H25 Sec. 2.2, Definitions 4–5). It is used as a KL regulariser on a reinforcement-learning policy with a decaying weight, and as hard masks for combinations never seen; it is not part of the score, which is 1/(1+NRMSE) (H25 Secs. 3.2–3.6). — [H25](https://arxiv.org/abs/2503.09592)
- S24 (polynomial model spaces) tabulates which model prior corresponds to which criterion: AIC ↔ exp(−n), BIC ↔ N^(−n/2), plus 1/n, uniform, and a normalisable prior 1/(d+1)^(n+1) for n parameters and degree d (S24 Sec. 3, Table 1, Eq. 18). Constants get explicit uniform or Gaussian priors, with the warning that the prior width changes the evidence through volume effects (S24 Sec. 3 end, Sec. 6.2). — [S24](https://arxiv.org/abs/2407.06259)
- According to PSR, Werner et al. (2022) use zero-mean isotropic Gaussian priors on all constants with one scale hyperparameter optimised to maximise the marginal likelihood, and a flat prior over functions (PSR Sec. 5). — [PSR](https://arxiv.org/abs/2304.06333)

### Inferences
- **[inference]** The corpus prior charges roughly 3.5 to 8 nats per operator, i.e. the same order as a hand-set cost of 3 per function, but differentiated: an extra additive term costs about 5.3 (+) plus about 4.0 (×) plus the parameter cost, a trigonometric function about 6, tan/tanh about 8.
- **[inference]** The ESR integer code for θ/Δ behaves like a scale-free prior p(θ) ∝ 1/|θ| at the resolution set by the data; this is why its parameter cost depends on |θ|/σ_θ and not on an arbitrary prior width.
- **[inference]** None of these priors has an element for an unknown function inside the expression. A "hole" would have to be added as its own symbol with its own prior probability, or be scored purely through its Gaussian-process evidence.

## How is the marginal likelihood or description length computed, what does a constant and an operator cost, and how does it scale with N?

### Takeaway
Three computable scores recur: BIC plus log-prior (cost ½·log N per constant, operator cost independent of N), the ESR code length (cost log(|θ|/Δ)+log 2 per constant with Δ from the Fisher information, growing as ½·log N), and the Laplace form of the fractional Bayes factor (cost ¼·log N per constant and the log-likelihood multiplied by 1 − N^(−1/2)). In every one of them the structure cost is fixed and only the constant cost grows with N.

### Cited Findings

**BIC plus prior**
- Description length H(m) = −ln ∫dθ p(D|m,θ)p(θ|m) − ln p(m) ≈ B(m)/2 − ln p(m), with B(m) = −2 ln L(θ̂) + (k+1) ln N; the +1 is the noise variance, which is unknown and set to its maximum-likelihood value. Explicitly: H(m) = (N/2) ln(2π s_y²) + N/2 + ((k+1)/2) ln N − ln p(m), with s_y² the mean squared residual (FF23 Eqs. 3–4, 11–13; GS25 Eqs. 5–7). — [FF23](https://arxiv.org/abs/2204.02704); [GS25](https://arxiv.org/abs/2507.19540)
- GS25 gives a second-order form: B2 = −2 log L(θ̂) + (k+1) log N + log|I(θ̂)|, with I the Fisher information matrix at the maximum-likelihood point (GS25 Eqs. 8–9). — [GS25](https://arxiv.org/abs/2507.19540)
- Scaling: the prior is "fixed (intensive)" and the marginal likelihood "grows linearly with the number of observations (extensive)", so the prior washes out as N → ∞ and selection is consistent for any prior that excludes no model (GS25 Sec. 3.1 and Sec. 4; G20 after Eq. 3). — [GS25](https://arxiv.org/abs/2507.19540)
- GS25 argues the (k+1)·log N term is part of the goodness of fit (it comes from integrating over constants), not a complexity penalty; complexity is only −log p(m) (GS25 footnote 3). — [GS25](https://arxiv.org/abs/2507.19540)
- Stated limits: BIC "may fail" when the number of points is small, where one needs a generalised BIC or numerical integration; and even within one data set BIC can be good for some models and poor for others, which is hard to diagnose (G20 after Eq. 3 and Discussion). — [G20](https://arxiv.org/abs/2004.12157)
- Iba et al. (per RF26) used L = 0.5·N·log MSE + 0.5·d·log N for polynomial trees (RF26 Sec. III-D1). — [RF26](https://arxiv.org/abs/2606.06567)

**ESR code length**
- L(D) = −log L(θ̂) + k·log(n) − (p/2)·log 3 + Σ_j log(c_j) + Σ_i [ ½·log(I_ii) + log|θ̂_i| ] (ESR Eq. 6). It follows from coding each constant to precision Δ_i, Taylor-expanding the log-likelihood (expected loss I_ii·Δ_i²/24), and minimising, which gives Δ_i = (12/I_ii)^(1/2) (ESR Eqs. 2–5). Only the diagonal of the Fisher matrix enters. — [ESR](https://arxiv.org/abs/2211.11461)
- If |θ̂_i|/Δ_i < 1 the constant cannot be distinguished from zero: it is set to 0, the likelihood recomputed and p reduced by 1 (ESR after Eq. 6, following Rissanen). — [ESR](https://arxiv.org/abs/2211.11461)
- Scaling: log L and I_ii both scale linearly with N, which introduces a (p/2)·log N term "reminiscent of" BIC; BIC is a special case of the description length (ESR Sec. IV-C and end of Sec. III). — [ESR](https://arxiv.org/abs/2211.11461)
- Worked values, 32 cosmic-chronometer points: θ0·x² has residual 8.36 + function 5.49 + parameter 2.53 = 16.39; θ0·x^θ1 has 8.35 + 6.93 + 5.08 = 20.36; θ0 + θ1·x³ has 7.28 + 12.48 + 3.76 = 23.51 (rank 39); θ0 + θ1·x^θ2 has 7.27 + 11.27 + 6.52 = 25.06 (rank 84) (ESR Table I). With 1590 supernovae the parameter part is 5.11 for the top one-constant function, 8.81 for θ0 + θ1·x³ and 12.19 for θ0 + θ1·x^θ2 (ESR Table II). — [ESR](https://arxiv.org/abs/2211.11461)
- Refinements in PSR: a joint (rotated rectangular) lattice replaces Σ ½·log I_ii − (p/2)·log 3 by ½·log det I + (p/2)·log ν_p with log ν_p = 1 − log 3; with a parameter prior the length becomes L̃ = −log Ĥ + ½·log det I^H + (p/2)·log ν_p + k·log n + Σ log c_α, where Ĥ is the maximum of likelihood × prior (PSR Sec. 2.2, Eq. 6). — [PSR](https://arxiv.org/abs/2304.06333)
- ESR considers the likelihood maximum only; replacing it by the Bayesian evidence is listed as future work (ESR Sec. V-C). — [ESR](https://arxiv.org/abs/2211.11461)

**Laplace approximation and fractional Bayes factor**
- Laplace: log Z ≈ log Ĥ + (p/2)·log 2π − ½·log det Î^H, expanded about the posterior maximum; dropping the O(p) term and replacing the determinant term by −(p/2)·log N gives −BIC/2 (PSR Eq. 3). PSR uses the full Eq. 3, with the Hessian by finite differences. — [PSR](https://arxiv.org/abs/2304.06333)
- Fractional Bayes factor (O'Hagan): compare models by q_i(b) = ∫ L·π dθ / ∫ L^b·π dθ, well defined for improper π; b = N^(−1/2) recommended as more robust than b = log N / N (PSR Eq. 8 and text). — [PSR](https://arxiv.org/abs/2304.06333)
- With a uniform prior and Laplace on both integrals: log Z ≈ (1 − b)·log L(θ̂) + (p/2)·log b. For b = N^(−1/2) this is "almost proportional to the BIC, but with an extra factor of 1/2 multiplying the p·log N term". The Fisher information cancels for any b, which "may be undesirable" because finely tuned constants are no longer penalised (PSR Eq. 11 and text). — [PSR](https://arxiv.org/abs/2304.06333)
- The same quantity is the "normalized marginal likelihood" of the NASA group: q̂ = γ^(N_θ/2) · L(θ*)^(1−γ), γ = 1/√N_d (BL25 Eqs. 3–4; RF26 Eqs. 11–12 give the derivation). — [BL25](https://arxiv.org/abs/2512.10849); [RF26](https://arxiv.org/abs/2606.06567)
- Accuracy of Laplace for this quantity: on a multimodal toy and a nonlinear toy (f0 = θ0²·x0 + θ1²·x1) Laplace is "very consistent but biased", and "less accurate even in a case that is unimodal and approximately Gaussian"; on 43 expressions produced by a genetic-programming code on Feynman problems the SMC and Laplace values are "correlated but different". Suggested practice: use Laplace, and SMC only where needed (L24 slides 8, 10, 13, 14; this source is the slide deck, not the paper). — [L24](https://ntrs.nasa.gov/api/citations/20240007699/downloads/gecco_2024_final.pdf)
- BL25 uses Laplace because SMC in an inner loop "was assumed" intractable, while noting Laplace is "orders of magnitude faster" but "less accurate for many common SR models" (BL25 Sec. 1). — [BL25](https://arxiv.org/abs/2512.10849)

**Sampling and exact integration**
- SMC with likelihood tempering yields both integrals of the fractional Bayes factor from one run if the tempering exponent passes through γ (RF26 Sec. III-B1, Eqs. 14–16; B22 Sec. 2). — [RF26](https://arxiv.org/abs/2606.06567)
- Nested sampling: S24 computes each model's evidence with MultiNest (400 live points, evidence tolerance 0.5, 3 to 13 dimensions), treats the numerical error as Gaussian and resamples it in each acceptance step; for the linear toy with Gaussian priors the evidence is analytic (S24 Sec. 6.2, Eq. 34). — [S24](https://arxiv.org/abs/2407.06259)
- Exact integration over linear coefficients by conjugacy is the basis of HierBOSSS; RF26 notes it restricts the model to be linear in its constants (RF26 Sec. III-B6 and IV). — [RF26](https://arxiv.org/abs/2606.06567)
- J19 does not marginalise: it samples structure and lt() constants jointly with reversible-jump MCMC (J19, "Jump between Spaces of Parameters", Eqs. 1–2). — [J19](https://arxiv.org/abs/1910.08892)

**Fixed-precision description length (AI Feynman 2.0)**
- A function costs k·log2(n) bits plus the bits of its constants; a real constant r costs ½·log2(1 + (r/ε)²) bits with a fixed precision floor ε = 2^(−30) (AIF2 Table 2). ESR criticises this: the precision "scales the parameter part … and hence leads to essentially arbitrary values" and "greatly penalises real numbers relative to integers or rationals"; ESR recommends choosing the precision per parameter from the Fisher information (ESR Sec. V-B). — [AIF2](https://arxiv.org/abs/2006.10782); [ESR](https://arxiv.org/abs/2211.11461)

### Inferences
- **[inference]** Cost per fitted constant at N = 100: BIC 2.30; fractional Bayes factor 1.15 (and log L multiplied by 0.9). At N = 15: BIC 1.35, fractional 0.68 with log L multiplied by 0.74. The ESR cost is log(|θ|/σ_θ) − 0.55 with σ_θ = I_ii^(−1/2), whatever N is: 1.75 for a constant known to 10 %, 4.06 for one known to 1 %, and removal below |θ|/σ_θ ≈ 3.46; N enters because σ_θ shrinks as N^(−1/2).
- **[inference]** Checking ESR Table I against Eq. 6: 5·log 3 = 5.49, 5·log 4 = 6.93, 9·log 4 = 12.48, 7·log 5 = 11.27, so the "function" column is exactly k·log n.
- **[inference]** A fixed cost per real-valued exponent (independent of N and of how well the exponent is determined) is the AI Feynman type of score that ESR calls arbitrary; a fixed cost per operator is what all the Bayesian and MDL scores use.
- **[inference]** For a model whose linear weights and unknown functions are integrated analytically, the "likelihood" in all formulas above is the exact marginal likelihood as a function of the remaining nonlinear constants and kernel hyperparameters; Laplace, ESR coding or the fractional form then apply to those remaining constants only.

## How do these scores treat a constant with a simple value compared with a free real constant?

### Takeaway
Only the description-length scores distinguish them. ESR charges log(c) nats for a natural number c against log(|θ|/Δ)+log 2 for a real; AI Feynman charges log2(1+|m|) bits for an integer and log2((1+|m|)·n) for a fraction m/n against a fixed-precision real, and actively "snaps" constants. BIC, Laplace and the fractional Bayes factor only count fitted constants, so a fixed integer is free.

### Cited Findings
- ESR: a constant c produced by simplification in a coefficient or exponent costs log(c) nats (natural-number code, lower bound of a prefix code; O(log log) terms ignored); a negative sign needs a negation operator counted in k and n. Real parameters cost log(|θ_i|/Δ_i) + log 2 (ESR Sec. III, footnote 5, Eq. 2). — [ESR](https://arxiv.org/abs/2211.11461)
- ESR does not search for integers: "when we optimise parameters we do not attempt preferentially to find integers or rational numbers over floats". Proposed extension: snap floats to integers or rationals, using the Fisher matrix "to do this by determining which integers or rationals are close enough to the best-fit float not to degrade the likelihood significantly"; also special nullary operators for π, e, √2 (ESR Sec. V-C). — [ESR](https://arxiv.org/abs/2211.11461)
- ESR example: θ0 + θ1·x³ was generated as x·x·x (complexity 9); written with pow(x, 3) (complexity 7) its description length "marginally decreases", moving it from rank 39 to 38 (chronometers) and 37 to 34 (supernovae) (ESR Sec. IV-B). — [ESR](https://arxiv.org/abs/2211.11461)
- AI Feynman 2.0: natural number n: log2 n bits; integer m: log2(1+|m|); rational m/n: log2[(1+|m|)·n]; real r: ½·log2(1+(r/ε)²), ε = 2^(−30) (AIF2 Table 2). After the search, "zero-snap, integer-snap and rational-snap" are applied to all real constants, generating for 3 constants 3 new models in which the 1, 2 and 3 constants closest to integers are rounded, then re-optimised and kept only if not Pareto-dominated (AIF2 Table 1 and the paragraph on improving the Pareto frontier). — [AIF2](https://arxiv.org/abs/2006.10782)
- BIC-type scores: k is "the number of parameters in m" (FF23 after Eq. 11). G20's operator set has dedicated pow2 and pow3 operations with their own prior costs, distinct from the general power ** (G20 Fig. 2B; values in the repository file: pow2 3.55, pow3 6.39, ** 6.05 for 2 variables, 5 parameters). — [FF23](https://arxiv.org/abs/2204.02704); [BMS repository](https://bitbucket.org/rguimera/machine-scientist/src/no_degeneracy/Prior/)
- Fractional Bayes factor: the cost (p/2)·log b depends only on the count p of fitted constants (PSR Eq. 11). — [PSR](https://arxiv.org/abs/2304.06333)
- In ESR data: θ0·x² (exponent fixed) scores 16.39 and θ0·x^θ1 with θ1 = 2.03 scores 20.36 on the same 32 points, almost identical residuals (8.36 vs 8.35) (ESR Table I). — [ESR](https://arxiv.org/abs/2211.11461)

### Inferences
- **[inference]** From ESR Tables I and II, freeing the exponent 3 in θ0 + θ1·x³ changes the parameter part by +2.76 (N = 32) and +3.38 (N = 1590) while the structure part with pow(x,3) would be 7·log 5 + log 3 = 12.36 against 11.27 for the free exponent. Net cost of a free exponent over the integer 3: about 1.7 to 2.3 nats in these two data sets. In Table I the gap between x² and x^θ1 is 3.97 nats (1.44 structure + 2.55 parameter). A hand-set 10 per non-simple exponent is several times larger than what ESR's code gives at these sample sizes.
- **[inference]** In the corpus prior a general power costs about 2.5 nats more than a square and about the same as a cube before its parameter is counted; with the parameter (½·log N = 2.3 at N = 100) a free exponent costs about 4.8 nats more than a square.
- **[inference]** A principled rounding rule in the ESR spirit: accept the simple value when the loss in log evidence is smaller than [log(|θ|/Δ) + log 2] − [code length of the simple value], with Δ = (12/I_ii)^(1/2). Both sides then depend on N through I_ii.

### Gaps
- No paper read specifies a code for simple fractions in a Fisher-information framework; the rational code is AI Feynman's fixed scheme only.
- ESR's snapping is a proposal, not implemented in the paper read.

## What does the literature say about the regime where the true formula cannot be recovered?

### Takeaway
FF23 shows a sharp transition: above a noise level s× the true model is not the minimum-description-length model for most data sets, so no method can identify it from the data alone. An upper bound for s× comes from the competition with the a-priori most probable (trivial) model: s× ≈ [⟨δ²⟩·N / (2Δ_M + (k*−1)·log N)]^(1/2), where ⟨δ²⟩ is the variance of the true function over the sampled range. ESR's forecasts give the same message in a concrete case: with 20 % errors about 1000 points are needed, with 10 % a few hundred.

### Cited Findings
- Definition: a model is learnable from a data set if no sampled model has a shorter description length than the true one. Learnability ρ(s_ε) is the fraction of data sets at noise s_ε for which this holds (FF23, "Phenomenology of the learnability transition", Fig. 3). — [FF23](https://arxiv.org/abs/2204.02704)
- Setup: models drawn from the corpus prior, two inputs uniform in [−2, 2], N ∈ {25, 50, 100, 200, 400}, 40 data sets per noise level, posterior sampled with the Bayesian machine scientist, noise variance unknown (FF23 Figs. 1–3, Methods). — [FF23](https://arxiv.org/abs/2204.02704)
- For "Model 1" at N = 100: all sampled models have positive gaps at low noise; for s_ε ≳ 0.6 some data sets yield models more plausible than the truth; for s_ε > 2 the true model is unlearnable for virtually all data sets. Trivial models appear suddenly: almost none sampled for s_ε < 2, most sampled models trivial or very simple for s_ε ≳ 3 (FF23 Fig. 2 and text). — [FF23](https://arxiv.org/abs/2204.02704)
- Three regimes: learnable (true model always recovered, predictions optimal); unlearnable (never recovered, predictions still optimal because error is dominated by noise); transition (recovered only for some data sets, predictions suboptimal on average). The peak of RMSE/s_ε coincides with the transition; the transition moves to higher noise as N grows (FF23 Fig. 3 and text). — [FF23](https://arxiv.org/abs/2204.02704)
- Bound. With H(m*) = (N/2)[log 2π⟨ε²⟩ + 1] + ((k*+1)/2)·log N − log p(m*) and, for the constant model, H(m^c) = (N/2)[log 2π(⟨ε²⟩+⟨δ²⟩) + 1] + log N − log p(m^c), equality gives s× = { ⟨δ²⟩ / [ (p(m^c)/p(m*))^(2/N) · N^((k*−1)/N) − 1 ] }^(1/2) (FF23 Eqs. 6–8). For N ≳ 100 and Δ_M ≡ H_M(m*) − H_M(m^c) of order 1: s× ≈ [⟨δ²⟩·N / (2Δ_M + (k*−1)·log N)]^(1/2) (FF23 Eq. 9). — [FF23](https://arxiv.org/abs/2204.02704)
- It is an upper bound: other models can overtake the true one at lower noise. Empirically the bound is close to the observed transition, and learnability curves for both models and all N collapse when plotted against s_ε/s× (FF23 Fig. 3e and text). — [FF23](https://arxiv.org/abs/2204.02704)
- Near s×, especially at small N, the minimum description length found is below both H(m*) and H(m^c): a set of other models (a "Rashomon set") becomes relevant (FF23 Fig. 4 and text). GS25 adds that near the transition these models are diverse and give "non-congruent descriptions of the same data", and that in empirical data "this situation seems to be the norm rather than the exception" (GS25 Sec. 6.2). — [FF23](https://arxiv.org/abs/2204.02704); [GS25](https://arxiv.org/abs/2507.19540)
- Since s× diverges with N, the true model is learnable at any finite noise for large enough N (FF23 after Eq. 9). The argument holds for any prior, since some model other than the true one is always the most probable a priori (FF23 Methods). — [FF23](https://arxiv.org/abs/2204.02704)
- Because the probabilistic approach is Bayes-optimal when models are drawn from the prior used, the transition is claimed as a limit for any algorithm (GS25 Sec. 6.2; FF23 abstract). — [GS25](https://arxiv.org/abs/2507.19540)
- FF23 also notes an untreated case: where the constants themselves cannot be learned even without noise, the true model should also be unlearnable (FF23 Discussion). — [FF23](https://arxiv.org/abs/2204.02704)
- ESR forecast with mock data from the Friedmann form θ0 + θ1·x³: with the current 20 % fractional errors about 10³ points are needed for it to have the minimum description length; halving the errors reduces this to "a few hundred"; with 1 % or 5 % errors it wins "even if one had only ten" points. With the real 32 points it ranks 39th, behind θ0·x² (ESR Sec. IV-C, Fig. 6, Table I). — [ESR](https://arxiv.org/abs/2211.11461)
- ESR on the nature of the selection: "MDL is not wedded to the notion that there exists a 'true' hypothesis"; it is "conservative, as one should only hope to recover the generating equation when data of sufficient quality and quantity are available". The top 150 functions are "effectively indistinguishable" where the data lie (z ≲ 1) and "diverge rapidly" outside (ESR end of Sec. III; Sec. IV-B, Figs. 4–5). About 40 of 5.2 million trial functions describe the data more economically than the Friedmann equation (ESR abstract). — [ESR](https://arxiv.org/abs/2211.11461)
- G20: identifying the correct model "requires a minimum amount of data points"; for its two-variable test expression with unit noise, 100 points sufficed (G20, "Validation … with synthetic data", citing Supplementary S3). At high noise in the Rössler system the selected models are "regularized versions" of the true equations with small terms dropped (G20 Fig. 4). — [G20](https://arxiv.org/abs/2004.12157)
- S24 toy: for y = θ0 + θ1·x + θ3·x³ the true model has posterior probability 0.84 at small noise; at large noise a constant model has 0.75 (S24 Fig. 3). An over-wide Gaussian prior on constants makes selection markedly worse because the prior volume dominates the evidence (S24 Sec. 5, Fig. 4 right). — [S24](https://arxiv.org/abs/2407.06259)

### Inferences
- **[inference]** Evaluating FF23 Eq. 8 for N = 100: with Δ_M = 10 nats and k* = 3 the bound is s× ≈ 1.7 times the standard deviation of the true function over the data; with Δ_M = 20 and k* = 4 it is 1.2; with Δ_M = 5 and k* = 2 it is 2.5. For N = 15 the same three cases give 0.47, 0.21 and 0.87; for N = 25: 0.73, 0.40, 1.20. So with about 15 points a formula with a prior cost of 10 to 20 nats is only identifiable when the noise is well below half the signal spread.
- **[inference]** The same algebra applied to any simpler competitor m′ instead of the constant model: m′ beats the true model when (N/2)·log(1 + ⟨δ²⟩/s²) < ΔH_M + (Δk/2)·log N, where ⟨δ²⟩ is the mean squared difference between m′ and the truth on the data, ΔH_M the difference in structure cost and Δk the difference in number of constants. At N = 100 the threshold RMS difference is 0.25·s (ΔH_M = 3, Δk = 0), 0.40·s (5, 1), 0.58·s (10, 2). At N = 15 it is 0.70·s, 1.16·s, 2.1·s. A wrong formula that stays within these distances of the truth over the sampled range is preferred by any score of this type, however it behaves outside the range.
- **[inference]** This is the published form of the weakness "a formula that fits within the noise is preferred even when wrong outside the data": the literature treats it as a property of the data, not a defect of the score, and answers it by reporting the set of near-optimal models rather than one.

### Gaps
- The closed forms of FF23's "Model 1" and "Model 2" are only in the figure, not in the extracted text; FF23's supplementary Fig. S1 (a model not drawn from the prior) was not opened.
- FF23 analyses the BIC approximation only; no result for exact evidence or for N below 25.
- No paper read quantifies identifiability between two non-trivial competing formulas beyond single examples.

## How do Bayesian methods search, and what does a run cost?

### Takeaway
Search is by Metropolis sampling over trees with parallel tempering (G20), reversible-jump MCMC over a fixed number of additive trees (J19), sequential Monte Carlo with genetic operators as proposals (BL25), or exhaustive enumeration to complexity 10 in one variable (ESR). Reported costs: thousands to tens of thousands of MCMC steps with 40 replicas (G20), 100,000 trees (J19), a population of 2000 with 10 MCMC moves per tempering step (BL25), and 33 to 150 CPU-hours per data set (ESR).

### Cited Findings
- G20 moves: node replacement (same arity), root addition/removal, and elementary-tree replacement (a subtree with at most one operation), attempted 45 %, 5 % and 50 % of the time, accepted by the Metropolis rule with proposal-ratio corrections. Expressions are reduced to a canonical form with Sympy and duplicates forbidden (G20 Materials and Methods). — [G20](https://arxiv.org/abs/2004.12157)
- G20 parallel tempering: 40 replicas at T_k = 1.05^k sampling exp[−B/(2T) + log p(f)]; T = ∞ is the prior, so hot replicas hold simpler expressions; only the T = 1 chain is used. The landscape is "extremely rugged" (G20, Fig. 3 caption and Methods). — [G20](https://arxiv.org/abs/2004.12157)
- G20 run sizes: 2500 steps on 400 points, equilibrating after 1000 to 1500 steps (Fig. 3); 10,000 sampled models per Rössler equation (Fig. 4); more than 18,000 for the Nikuradse data with four restarts (Fig. 5). Cost in N enters only through the least-squares fit for the BIC. No wall-clock time is given. A sign of failure would be different description-length distributions from different runs (G20 Discussion). — [G20](https://arxiv.org/abs/2004.12157)
- J19 moves: Stay (resample lt constants), Grow, Prune, Delete, Insert, ReassignOperator, ReassignFeature, with probabilities that shrink growth as the tree gets large; the K trees are updated in turn; dimension changes use reversible jump with auxiliary variables. 100,000 trees per run in the experiments, "typically … less than 10,000 candidates" to reach stable results; K = 2 (J19, "Structure Transition Kernel", "Parameter Settings"). — [J19](https://arxiv.org/abs/1910.08892)
- BL25: population of weighted expressions moved through targets π(M)·q̂(M)^φ_t, φ from 0 to 1 chosen adaptively by bisection to keep the effective sample size at 95 %; stratified resampling; rejuvenation by 10 Metropolis moves whose proposals are genetic crossover and mutation (asymmetric, justified by SMC not needing strict ergodicity); population 2000; constants refitted by gradient-based optimisation for every proposal (BL25 Sec. 1.1). The baselines were given T × 10 generations for equal compute; no wall-clock time is given. — [BL25](https://arxiv.org/abs/2512.10849)
- BL25 arguments against MCMC here: serial, low acceptance without tuned proposals, trouble with multimodal posteriors (BL25 Introduction and Sec. 1). SMC visits about 50 % as many unique expressions as the genetic baselines but accepts more distinct ones into the population (BL25 Sec. 3, Fig. 7). — [BL25](https://arxiv.org/abs/2512.10849)
- ESR: all trees up to complexity 10 from {x, a, inv, +, −, ×, ÷, pow} give 5.2 million valid trees, 134,234 unique, 119,861 with constants to fit. Generation and duplicate removal took 46 minutes on 196 cores at complexity 10 and scales about as (1.5·k)^c for k basis functions; it is done once per operator set. Constants: BFGS from up to 30 random starts, stopping after 5 agree. One benchmark with 10⁵ points took about 150 CPU-hours including generation, 33 with precomputed functions (ESR Secs. II-D, II-E, V-B). Limits: one variable, complexity ≲ 10 (ESR Sec. V-A). — [ESR](https://arxiv.org/abs/2211.11461)
- ESR found that a genetic-programming code (PySR) matched the true Pareto front only up to complexity 6 on the 32-point data and missed fits better by up to 2.0 in log-likelihood at complexity 7 to 10, unchanged between 5 and 10 hours (ESR Sec. V-B). — [ESR](https://arxiv.org/abs/2211.11461)
- S24: Metropolis walk on a lattice of polynomial models (number of terms × degree), acceptance by evidence ratio × prior ratio × a combinatorial proposal correction (Eqs. 6–10), a Poisson number of lattice steps per proposal, evidences cached so longer chains are cheap; only a fraction of the model space is ever evaluated (S24 Secs. 2, 6.3). — [S24](https://arxiv.org/abs/2407.06259)
- H25: policy-gradient reinforcement learning with a tree-structured recurrent network, batch size 1000, constants tuned with Adam then BFGS (H25 Sec. 3.5, Algorithm 1, Sec. 4.2). — [H25](https://arxiv.org/abs/2503.09592)
- GS25's position: heuristic search is acceptable for finding a model, but model averaging and learnability analysis need sampling from the posterior (GS25 Sec. 7). — [GS25](https://arxiv.org/abs/2507.19540)

### Inferences
- **[inference]** None of these methods exploits analytic marginalisation of linear weights during search except the forest methods; G20 and BL25 refit all constants numerically for every proposed tree.
- **[inference]** ESR-style enumeration is feasible only for one input; for 2 to 5 inputs the published options are tempering MCMC or SMC populations.

### Gaps
- No paper read reports wall-clock time per data set for the MCMC or SMC methods in a 100-point, 2-to-5-input setting.

## What do they report as output, and does any method abstain or report a partial result?

### Takeaway
Outputs are a most-plausible formula plus, in the Bayesian methods, a sample or weighted set of formulas used for model-averaged prediction; intervals on constants or predictions are rare (4 of 18 papers in the survey). No method read abstains or returns a formula with an explicitly unknown part; the nearest behaviours are falling back to a simpler or trivial model, dropping constants indistinguishable from zero, and showing where the sampled models disagree.

### Cited Findings
- G20: the maximum-a-posteriori (minimum-description-length) expression; a posterior sample; the predictive distribution p(y|D,x) ≈ Σ_i δ(y − f_i(x; θ_i*))·p(f_i|D) with constants at their maximum-likelihood values; and the "median predictive model", the sampled model closest to the ensemble median. For the Nikuradse data no single expression dominates, and the ensemble median extrapolates correctly where individual sampled models do not (G20 Eq. 4, Fig. 5 C–F and text). — [G20](https://arxiv.org/abs/2004.12157)
- GS25: full model averaging is p(y|D,x) = Σ_m ∫dθ δ(y − m(x,θ))·p(m,θ|D), approximated by an equal-weight average over K models sampled by MCMC with constants at maximum likelihood (GS25 Eqs. 17–18). In general p(m̂|D) ≪ 1, so the single best model is "just an approximation" (GS25 Sec. 6.1). — [GS25](https://arxiv.org/abs/2507.19540)
- ESR: the complete ranking of all functions with their description lengths; proposes propagating functional uncertainty by "weighting each function by the exponential of the negative description length", and notes that priors can be changed and functions reweighted afterwards without refitting (ESR Sec. V-B, V-C). — [ESR](https://arxiv.org/abs/2211.11461)
- PSR Table 2 shows how close the top functions are on 1590 points: under MDL ranks 2 to 4 are 0.78, 0.83 and 0.91 nats behind rank 1; under MDL with the language-model prior 1.40, 1.63, 1.72 (PSR Table 2). — [PSR](https://arxiv.org/abs/2304.06333)
- BL25: the final weighted population approximates π(M|D); outputs are a most-probable expression and a histogram of the models' predictions over x. Regions of disagreement are read as "an area where caution might be exercised when making predictions and also an area where additional training data might be especially insightful" (BL25 Sec. 1.2, Fig. 1b). Credible intervals need a further per-model calibration of constants by MCMC or SMC (BL25 end of Sec. 1.2). — [BL25](https://arxiv.org/abs/2512.10849)
- BL25 model choice: taking the mode of the final population beats both best-training-score and a 20 % validation split in test error and in ground-truth identification (BL25 Fig. 6). — [BL25](https://arxiv.org/abs/2512.10849)
- B22: the Bayesian fitness gives, per expression, the joint distribution of constants and noise level, usable for predictions with uncertainty by Monte Carlo (B22 Sec. 4). — [B22](https://ntrs.nasa.gov/api/citations/20220001900/downloads/smcbingo_gecco22.pdf)
- S24: normalised posterior model probabilities (0.934 for the constant model, 0.034 for the next), per-term inclusion probabilities, marginal posteriors over degree and number of terms, and a parameter posterior for the top model (S24 Sec. 6.3, Figs. 5–7, conclusion vi). — [S24](https://arxiv.org/abs/2407.06259)
- J19: posterior-mode expressions and RMSE; no intervals (J19 Experiments). — [J19](https://arxiv.org/abs/1910.08892)
- Survey: of 18 papers on uncertainty in symbolic regression only four compute confidence, credible or prediction intervals. Available tools: delta-method intervals f ± s·(vᵀH⁻¹v)^(1/2)·t and prediction intervals with 1 + vᵀH⁻¹v; profile-likelihood intervals (asymmetric, reveal unbounded parameters, costlier than the delta method); split conformal prediction (distribution-free coverage but wide with few points); MCMC credible and posterior-predictive intervals; Bayesian model averaging over the final population (RF26 Secs. II-B2, II-B3, II-C2, III-B5, III-C2, IV). — [RF26](https://arxiv.org/abs/2606.06567)
- Survey's open question: how to verify that an approximated posterior over structures is close to the true one, and how to quantify structural uncertainty (RF26 Sec. IV). — [RF26](https://arxiv.org/abs/2606.06567)
- Nearest things to abstaining: at high noise the Bayesian machine scientist returns an underfit or trivial model, judged "reasonable" because the reducible error is small against the noise (GS25 Sec. 5, Fig. 1; FF23 Fig. 2b); ESR sets constants with |θ|/Δ < 1 to zero (ESR after Eq. 6); profile likelihood flags unbounded intervals (RF26 Sec. III-C2). — [GS25](https://arxiv.org/abs/2507.19540); [ESR](https://arxiv.org/abs/2211.11461); [RF26](https://arxiv.org/abs/2606.06567)

### Inferences
- **[inference]** G20/GS25 model averaging holds constants at their best-fit values, so its spread reflects structural uncertainty only; parameter uncertainty within a model is not included.
- **[inference]** A partial expression with a Gaussian-process remainder is absent from all papers read; in their terms the fallback at high noise is the trivial symbolic model, not a nonparametric one. G20 compares against a Gaussian process only as a competing predictor (G20 Fig. 5 C–D).
- **[inference]** A decision rule "report as undecided when the runner-up is within about 1 to 3 nats" is consistent with the gaps in PSR Table 2 and with the Jeffreys-scale remark in S24 (conclusion ii), but no paper states such a rule.

### Gaps
- No paper read defines a threshold on posterior probability or description-length gap below which a result is declared undecided.
- The four interval-computing papers named by the survey (its refs. 41, 8, 39, 11) were not read individually.

## Results on small and noisy data sets

### Takeaway
Evidence-based scores stop overfitting at small N and adapt complexity to the noise, but they then select simpler-than-true formulas: with 32 points and 20 % errors the generating form ranks 39th under MDL, and with N = 10 to 20 the Bayesian methods return low-order models.

### Cited Findings
- G20: two-variable expression x1(θ1 + x2)·cos(x1)/[θ2·log θ2], inputs in [−2, 2]², noise N(0, 1): recovered from 400 points (Fig. 3) and from as few as 100 (Supplementary S3, fig. S3, cited in text) where three other methods fail with 400. Three small real data sets (funding success, cell-to-cell stresses, salmon stocks): the method finds at least one model that is better than the published models on at least one of plausibility, BIC and cross-validation error and worse on none (Supplementary Tables S5–S7, cited in text). — [G20](https://arxiv.org/abs/2004.12157)
- FF23: prediction RMSE of the selected model equals the noise level "except for small N and some intermediate values of the observation noise"; a neural network (4 hidden layers of 10 units) is worse at low noise (FF23 Fig. 1 c–f). — [FF23](https://arxiv.org/abs/2204.02704)
- GS25: y = −2.3 + 4.1·x and y = 31, N ∈ {10, 100, 1000}, σ ∈ {0.05, 0.5, 5, 50}. The Bayesian machine scientist finds the right model except at high noise, where it underfits; PySR with defaults overfits at high noise even with many points, and never returns the constant model (GS25 Figs. 1–2, Sec. 5). — [GS25](https://arxiv.org/abs/2507.19540)
- B22: N = 20 points from 2·sin(x) + 3 with σ from 0 to 1.0, operators restricted to +, −, ×, 50 data sets per noise level, population 120, 1000 generations. With the normalised marginal likelihood as fitness the number of constants settles and does not grow, complexity falls slightly with further evolution, simpler models are chosen at higher noise, and test error does not rise; RMSE fitness overfits. Exception: with zero noise RMSE fitness is better (B22 Figs. 2–6). — [B22](https://ntrs.nasa.gov/api/citations/20220001900/downloads/smcbingo_gecco22.pdf)
- BL25: 25 points from a Gaussian bump with noise, operators +, −, × (Sec. 1.2, Fig. 1). Twelve hard Feynman problems, 3 to 8 inputs, 500 training points, noise 10 % of median |y|, 20 repeats: SMC overfits on 5 of 12 problems against almost all for the genetic baselines; using the same score inside a genetic algorithm helps only "modestly" (BL25 Sec. 2, Figs. 4–6; Sec. 3). — [BL25](https://arxiv.org/abs/2512.10849)
- ESR: 32 points, about 20 % errors: best θ0·x² (16.39); the generating-type form θ0 + θ1·x³ ranks 39th (23.51) (Table I). 1590 points: best θ0·x^x (718.22); θ0 + θ1·x³ ranks 37th (723.13) (Table II). — [ESR](https://arxiv.org/abs/2211.11461)
- PSR: five one-variable benchmarks with noise equal to half the standard deviation of y, five data sets per size, exhaustive candidates to complexity 8. Maximum likelihood never puts the truth in the top two; PySR's "score" often fails and is not consistent as N grows; ESR's MDL is best overall (always right for √x; needs more points for the linear and 1.3 + 0.13√x cases); MDL with the language-model prior recovers 1.57 + 2.43x only at about 10⁴ points but is best for 213.81(1 − e^(−0.547x)) (PSR Sec. 3, Table 1, Fig. 2). — [PSR](https://arxiv.org/abs/2304.06333)
- PSR on real data: the language-model prior removes x^x-type functions from the top four and lifts θ0 + θ1·x³ to rank 4; with the fractional Bayes factor the top function is still "somewhat unappealing" (PSR Sec. 4, Table 2). — [PSR](https://arxiv.org/abs/2304.06333)
- J19: 100 training points, two inputs in [−3, 3], no noise stated; K = 2 trees; on the in-range test set BSR has lower mean RMSE than genetic programming on 4 of 6 functions (worse on f2 and on the non-additive f6), with large spread across 50 runs (e.g. f1 test 2.04 ± 3.27 vs 4.25 ± 4.59) (J19 Table 1); expression sizes in Table 2. — [J19](https://arxiv.org/abs/1910.08892)
- H25: recovery rates at noise 0 to 0.1 on Feynman and ODEbase problems are higher with the domain prior for all three search methods; shown only as curves (H25 Fig. 9). In one of four case studies the prior did not help, attributed to prior bias (H25 Sec. 4.2). — [H25](https://arxiv.org/abs/2503.09592)
- RF26 could not reproduce the ground-truth recoveries reported for HierBOSSS and VaSST after correcting inconsistencies in their code (RF26 Sec. III-B6). — [RF26](https://arxiv.org/abs/2606.06567)

### Inferences
- **[inference]** Nothing read tests below N = 10, and the only N ≤ 25 experiments (B22, BL25 demo, FF23 at N = 25, GS25 at N = 10) use one input or a deliberately incomplete operator set, so there is no published reference for 2 to 5 inputs with about 15 points.
- **[inference]** In these results spurious terms at small N are controlled by structure costs of several nats per term (corpus prior) or by k·log n; a parameter penalty alone (BIC) is small at N = 15 (1.35 nats per constant).

### Gaps
- Supplementary figures and tables of G20 and FF23 were not opened; numbers there are cited only as the main texts describe them.
- H25 gives no numerical table of recovery rates.

## Which concrete elements could replace hand-set costs, and what would each need?

### Takeaway
The literature offers drop-in replacements for each hand-set piece: a Fisher-information or fractional-Bayes cost per fitted constant in place of a fixed exponent cost, a corpus-based or code-length structure prior in place of a flat cost per function, an integer/rational code for simple values, and reporting of the near-optimal set with a learnability check in place of a single winner. It also says which part is already principled: a structure cost that does not grow with N.

### Cited Findings
- Structure priors with public code or values: corpus α_o, β_o files for selected numbers of variables between 1 and 39 ([BMS repository](https://bitbucket.org/rguimera/machine-scientist/src/no_degeneracy/Prior/)); Katz back-off model and its 161 training equations (github.com/DeaglanBartlett/katz, PSR Sec. 6) — [PSR](https://arxiv.org/abs/2304.06333); ESR code and function sets (github.com/DeaglanBartlett/ESR, ESR data availability) — [ESR](https://arxiv.org/abs/2211.11461); SMC symbolic regression (github.com/nasa/pysips, BL25 Introduction) — [BL25](https://arxiv.org/abs/2512.10849).
- ESR recommends that its Eq. 6 "be incorporated into all SR algorithms" as a stand-alone selection statistic; it needs the maximised likelihood, the diagonal Fisher information at the optimum (finite differences), and the node and operator counts (ESR Sec. V-B, Sec. III). — [ESR](https://arxiv.org/abs/2211.11461)
- The fractional-Bayes form needs only the maximised likelihood, the number of constants and N: log q̂ = (1 − N^(−1/2))·log L̂ − (p/4)·log N (PSR Eq. 11; BL25 Eq. 4). — [PSR](https://arxiv.org/abs/2304.06333)
- Known weaknesses of each: BIC unreliable at small N (G20); Laplace biased for nonlinear or multimodal posteriors (L24); fractional form blind to fine tuning (PSR Sec. 2.3); count-based prior blind to nesting (PSR Sec. 1); language-model prior sensitive to the corpus and able to assign high probability to unseen combinations of common pieces (PSR Sec. 4; RF26 Sec. III-B3); learning context-dependent priors needs a large equation set (RF26 Sec. IV); explicit parameter priors move the evidence with their width (S24). — [G20](https://arxiv.org/abs/2004.12157); [L24](https://ntrs.nasa.gov/api/citations/20240007699/downloads/gecco_2024_final.pdf); [PSR](https://arxiv.org/abs/2304.06333); [RF26](https://arxiv.org/abs/2606.06567); [S24](https://arxiv.org/abs/2407.06259)
- On benchmarks the plain ESR code (no corpus prior) selected the truth most often; the corpus-informed prior helped on real physical data (PSR Sec. 6). — [PSR](https://arxiv.org/abs/2304.06333)
- Stronger penalisation of complex models (AIC-, BIC-type or the normalisable prior) performed better than flat or 1/n model priors on polynomial toys with medium and large noise (S24 Sec. 5, Fig. 4 centre). — [S24](https://arxiv.org/abs/2407.06259)

### Inferences
All items below are **[inference]**: proposals assembled from the cited material, with what each would need.

1. **Cost of fitted nonlinear constants and kernel hyperparameters.** Replace ½·log n by either (a) the ESR term log(|θ_i|/Δ_i) + log 2 with Δ_i = (12/I_ii)^(1/2), dropping a constant when |θ_i|/Δ_i < 1; (b) the full Laplace term −½·log det I + (p/2)·log 2π plus a log prior density; or (c) the fractional form. Needs: the Hessian of the negative log evidence with respect to the fitted constants at the optimum for (a) and (b) (diagonal only for (a)); nothing new for (c). (a) needs no prior width; (b) does; (c) does not penalise sharply tuned constants. All three grow with N, which the present fixed costs do not. For scale parameters such as kernel amplitudes and length scales, the ESR form's log|θ| term is natural; a parameter that can be zero or negative needs the sign bit.
2. **Exponents.** Treat a free exponent as an ordinary constant under item 1 and a simple value by its code length: log(c) nats for a natural number (ESR) or log(1+|m|) + log(n) for a fraction m/n (AI Feynman, converted to nats). Round when the loss in log evidence is less than the difference. Needs: I_ii for the exponent, which item 1 already supplies. Expected size of the difference at N around 100: 2 to 4 nats rather than 10.
3. **Cost per symbolic function.** Options in increasing information: k·log n (no data needed); corpus α_o + β_o·n_o per operator (values available; choose the file by number of inputs and constants, or refit with the published procedure on a chosen corpus); bigram parent-to-child model (public code; would need the expression tree in its format and, ideally, retraining on a corpus that matches the target domain). A fixed cost independent of N is consistent with all of them. The hole itself has no counterpart: it needs a chosen prior weight, e.g. one more "operator" in the count or in the bigram vocabulary.
4. **Small N.** BIC is the weakest element below about 25 points. With linear weights and holes integrated exactly, the remaining constants are few, so direct numerical integration, nested sampling (as S24) or SMC (as B22) over them is affordable per candidate; the published settings are 400 live points or an SMC run per model. A cheaper step is GS25's second-order term log|I|. A proper prior on the remaining constants is then required, and S24 shows its width matters.
5. **Reporting.** Keep the ranked candidates and convert score gaps to weights exp(−ΔL) (ESR, G20). Report (i) the weight of the top formula, (ii) the spread of the candidates' predictions inside and outside the data range (BL25 Fig. 1b), and (iii) the FF23-type bound: for the selected formula against the hole-only or simpler alternative, the noise level or N at which the gap would change sign, computed from (N/2)·log(1 + ⟨δ²⟩/s²) versus ΔH_M + (Δk/2)·log N. This gives a stated reason for returning the partial expression instead of a formula.
6. **What the literature does not solve.** A formula that agrees with the truth to within the thresholds in the learnability section is preferred by every score here; only extra information (a prior on behaviour outside the range, more data, or wider coverage) changes that. ESR and G20 handle it by showing the diverging alternatives.

### Gaps

- The corpus prior values are per (inputs, constants) pair and were fitted for the Bayesian machine scientist's operator set and 50-node cap; their transfer to another operator set is untested in the papers read.
