## 1. Cohrs et al. (ICLR 2024 workshop): what is the semiparametric part, is it integrated out, how is the symbolic part scored, does the unknown part stay in the answer, and what are the experiments?

### Takeaway

The full text could not be opened, so the account below rests on the abstract, on the authors' own later code repository and on search-engine summaries of the PDF. All three agree: "semiparametric" names the hybrid-modelling problem (a known parametric part with a parameter of interest, times or plus an unknown function), and the "hybrid Bayesian machine scientist" fills the unknown function with a symbolic expression found by the Bayesian machine scientist, in place of the neural network used by the baseline. No source mentions a Gaussian process, and no source says that a nonparametric function is integrated out. Points, noise levels and numerical results could not be established.

### Cited Findings

- Bibliographic: Kai-Hendrik Cohrs, Gherardo Varando, Roger Guimerà, Marta Sales-Pardo, Gustau Camps-Valls, "Semiparametric Inference and Equation Discovery with the Bayesian Machine Scientist", ICLR 2024 Workshop on AI4DifferentialEquations in Science (poster). No arXiv link and no code link on either listing; the only full-text link is OpenReview. — [ICLR page](https://www.iclr.cc/virtual/2024/21401); [ML Anthology entry](https://mlanthology.org/iclrw/2024/cohrs2024iclrw-semiparametric)
- Abstract, verbatim: "Hybrid modeling, combining machine learning with physical equations, is promising in many fields of science, in particular for climate and Earth Sciences, but faces challenges like interpretability, inconsistent extrapolation, lack of speed, and robust inference. Here we show that the Bayesian machine scientist, a Bayesian approach to symbolic regression is an ideal choice for the challenges in the hybrid modeling task. We formulate the hybrid Bayesian machine scientist and showcase its potential in the example of modeling ecosystem respiration with the Q10 model. Specifically, we show that our proposed hybrid equation discovery method (i) extracts the correct equations, (ii) extrapolates better in different scenarios than the non-hybrid and deep-learning-based baselines, and (iii) is able to infer more accurately parameters of interest, even in the presence of equifinality. We anticipate a spur of development of hybrid equation discovery algorithms in the sciences to approach fully interpretable data-driven models." — [ICLR page](https://www.iclr.cc/virtual/2024/21401)
- Search-engine summary of the indexed PDF (not read by me; treat as unverified): the paper compares a "hybrid neural network (HNN)", in which a neural network estimates the respiration term and Q10 is a parameter, with the "hybrid Bayesian machine scientist (HBMS)"; "Figure 1 shows estimated Q10 values over 100 models of a) HNN and b) HBMS each"; the first page carries the line "Accepted at the ICLR 2024 Workshop on AI4Differential Equations In Science". — [OpenReview PDF, as indexed](https://openreview.net/pdf?id=7YqV4deFAc)
- The first author's public repository "semi-param-hybrid-modeling" (snapshot of 30 September 2025, commit c0655042) describes the framework the two methods belong to. Its README: "Physical knowledge (fp) is encoded as parametric equations with unknown parameters"; "Learned components (fa) capture residual patterns using neural networks or symbolic regression"; "Hybrid equations combine both components (e.g., `y = fp(x, θ) + fa(x)`, `y = fp(x, θ) * fa(x)`)". Supported forms: `fp + fa`, `fp * fa`, `fp / fa`, `a0 / (fp + fa)`. — [GitHub: KaiHCohrs/semi-param-hybrid-modeling, README.md](https://github.com/KaiHCohrs/semi-param-hybrid-modeling)
- Same README, on the two model types. The neural one is available: "Learned component: Multi-layer perceptron with batch normalization"; "Joint optimization: Simultaneous learning of network weights and physical parameters"; "Ensemble training with bootstrap sampling"; default `ensemble_size: 100`. The symbolic one is listed as "Hybrid Bayesian Machine Scientist (HBMS) — Coming Soon", with planned features "Symbolic regression for learned component", "Bayesian parameter inference via MCMC", "Full posterior over equations and parameters", "Model selection and complexity control", and the use case "Discover interpretable equations while inferring physical parameters". — [GitHub: KaiHCohrs/semi-param-hybrid-modeling, README.md](https://github.com/KaiHCohrs/semi-param-hybrid-modeling)
- Same repository: the HBMS config template holds only MCMC settings (`samples: 100`, `burn_in: 1000`, `lag: 25`), and the base class docstring reads "This class combines physical knowledge (parametric component) with learned components (non-parametric component). It provides a unified interface for different hybrid modeling approaches including neural network-based (EnsembleHybridJNN) and symbolic regression-based (EnsembleHybridBMS) methods." The code of the HBMS itself is not in the snapshot. No file in the repository contains "Gaussian process", "marginal" or "kernel" (checked by search over a clone). — [configs/hbms_base.yaml and src/sphm/sphm/hybridmodel.py](https://github.com/KaiHCohrs/semi-param-hybrid-modeling)
- How the Bayesian machine scientist scores an expression, in the words of four of the five authors in November 2026: the description length is `H(f) = −log p(D, f)`; "using Laplace's approximation around the maximum-likelihood estimator" it becomes `H(f) ≈ B(f)/2 − log p(f)`, where `B(f)` "is the Bayesian information criterion" and `p(f)` is the structural prior; the search is "a Metropolis chain over expression trees" with parallel tempering (§II, Eqs. 2–3). The only mention of hybrid modelling in that paper is as future work: "Embedding causalBMS inside hybrid modeling pipelines would provide explicit mechanism candidates for downstream physical evaluation" (§IV). — [arXiv:2611.12458](https://arxiv.org/abs/2611.12458)
- The Q10 model that both papers of this group use: `Reco(X, TA) = Rb(X, TA) · Q10^((TA − TA_ref)/10)`, with `Rb` the base respiration and `Q10` the temperature sensitivity; "A common hybrid modeling approach amounts to using a NN as an estimator for Rb, treating Q10 as a trainable parameter, and fitting everything end-to-end with gradient descent" (Box 1, Eq. 2). Equifinality: for any `c > 0` the factor `c^((TA − TA_ref)/10)` can move between `Rb` and the exponential term, so a flexible `Rb` that depends on `TA` leaves `Q10` unidentified (Box 1, Eq. 3). — [arXiv:2402.13332](https://arxiv.org/abs/2402.13332)
- The related double-machine-learning paper (Cohrs, Varando, Carvalhais, Reichstein, Camps-Valls; read in full where cited) is a different method and contains no symbolic regression: a search of its text for "symbolic", "equation discovery" and "machine scientist" finds nothing. Model: `Y = θ(X)·f(T) + g(X, W)` with `f` known and `θ`, `g` nonparametric (Eq. 1). Procedure ("partialling out", §2): fit `E[Y|X,W]` and `E[f(T)|X,W]` with any regressor, form the two residuals, and estimate `θ` by least squares of one residual on the other; "it is important to split the data and perform the first two fitting steps … on a different data subset than the last fitting step", i.e. cross-fitting. The nuisance functions are estimated and subtracted, not integrated out; `g` is then obtained as a plug-in or by a final fit on residuals and stays in the model as a fitted regressor. — [arXiv:2402.13332](https://arxiv.org/abs/2402.13332)
- Experiments of the double-machine-learning paper (not of the workshop paper): synthetic respiration built from FLUXNET forcings with true `Q10 = 1.5` (also 1.25 and 1.75), 100 datasets at each of several sample sizes; on measured data, "approximately 10% of the nighttime data for training (4331 data points)", 2003–2007 for training and 2008–2009 for testing; the end-to-end neural hybrid with `TA` as a driver of `Rb` returns `Q10` "on average, between 2.1 and 2.3 over all sample sizes" against the true 1.5 (§3.1, §4.1.1). — [arXiv:2402.13332](https://arxiv.org/abs/2402.13332)

### Inferences

- (Inference from the README, the config and the "100 models" of the reported Figure 1.) In the hybrid Bayesian machine scientist the unknown function `fa` (here the base respiration `Rb`) is represented by symbolic expressions sampled by the Bayesian machine scientist's Markov chain, with the known part `fp` (the `Q10` term) held as fixed structure and its parameter fitted along with the expression's constants. The 100 "models" are then 100 sampled expressions (config: `samples: 100`), each giving one estimate of `Q10`, set against 100 bootstrap-trained networks for the neural baseline (`ensemble_size: 100`). The parameter of interest is thus averaged over sampled symbolic forms of the nuisance function. This is a reading of the repository, not of the paper.
- (Inference.) Under that reading the answers to the key questions are: the semiparametric part is a neural network only in the baseline; in the proposed method it is symbolic, so there is no nonparametric part to integrate out, estimate and subtract, or cross-fit; the score is the Bayesian machine scientist's description length (BIC plus structural prior), which is a Laplace approximation to the marginal likelihood over an expression's constants, not over an unknown function; and the unknown part does not stay nonparametric in the reported answer ("fully interpretable data-driven models").
- (Inference.) The word "semiparametric" in the title is used as in econometrics and in the group's double-machine-learning paper: a parameter of interest in the presence of an unknown nuisance function. It does not signal a GP or a marginalised function.
- The conceptual overlap with GP holes is the problem statement: an expression that is partly given and partly unknown, combined by sum, product or quotient, inside which a parameter is inferred. The treatment of the unknown part is the opposite of ours: it is searched symbolically from the start, never held as a function with a prior.

### Gaps

- **The full text was not read.** Not established from the paper itself: the model equations, whether the score is modified for the hybrid setting, the prior over expressions, the number of points, the noise levels, the extrapolation scenarios, the baselines' details, and all numerical results. Someone with a browser can settle these in a few minutes at the OpenReview link; the two things to check are (a) that `Rb` is a Bayesian-machine-scientist expression throughout and no neural network or GP is fitted inside the search, and (b) that the score is the unmodified description length.
- No journal version, arXiv version, thesis text or conference abstract of this work was found. The first author's doctoral project is listed as "Statistical Inference in Deep Science-Aware Models" (Universitat de València); no repository copy of a thesis was found. — [ELLIS project page](https://ellis.eu/projects/statistical-inference-in-deep-science-aware-models)
- The repository lists the symbolic method as not yet released, so its code could not be read either.

## 2. Otte (2013, 2014): is the GP fitted to the residual of a fixed symbolic model, or is the pair selected jointly, and by what criterion?

### Takeaway

Sequentially, on a fixed symbolic model: Eureqa finds the formula by training mean-squared error, a GP regression is then fitted to its residuals, and the GP's contribution is clipped to ±γ so that the combined model never departs from the formula by more than γ. Nothing is selected jointly, no marginal likelihood compares structures, and the GP is used only through its predictive mean.

### Cited Findings

- Three texts by Clemens Otte (Siemens) describe the construction: the ESANN 2013 paper "Learning Regression Models with Guaranteed Error Bounds" (pp. 543–548), the Springer chapter "Safe and Interpretable Machine Learning: A Methodological Review" (Computational Intelligence in Intelligent Data Analysis, SCI 445, pp. 111–122, 2013), and "Interpretable semi-parametric regression models with defined error bounds", Neurocomputing 143 (2014) 1–6. Only the first is open; the Neurocomputing paper's first reference is the ESANN paper. — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf); [doi:10.1007/978-3-642-32378-2_8](https://doi.org/10.1007/978-3-642-32378-2_8); [doi:10.1016/j.neucom.2013.11.042](https://doi.org/10.1016/j.neucom.2013.11.042); [Crossref record with reference list](https://api.crossref.org/works/10.1016/j.neucom.2013.11.042)
- Model (ESANN §2, Eq. 1): `f(x) = a(x) + g_γ(r(x))`, "where a is an analytical (that is, fully interpretable and verified) model, r is a residual model and g_γ provides a limitation. We use g_γ(x) = max(min(x, γ), −γ)". "The additive combination is chosen because it facilitates the training of the submodels and the interpretation of the overall model." — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- Order of fitting (ESANN §1): the symbolic model "is easily interpretable but has only moderate accuracy. Thus, a second function is learned on the residuals of the first function in order to improve the accuracy." The formula comes from Eureqa: "Using the mean-squared error to guide the search on the complete training set and taking the model having the smallest training set error" (§3.1); "Alternatively, any method providing a fully interpretable model may be used" (§2). — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- What is done with the GP (ESANN §2, Eqs. 2–3): "The residual model r is learned as a Gaussian Process (GP), which is a linear smoother using a weighted average of the stored training outputs", `r(x) = Σ α_i k(x_i, x)`, `α = (K + σ_n² I)⁻¹ y`; for large data the Subset-of-Regressors approximation is used. Kernel: squared exponential with one length scale per input; "In total 23 hyperparameters … are optimized during training" (§3). The conclusions call this "optimizing the hyperparameters by gradient descent" (§4); the objective is not named. — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- The GP's uncertainty is not used; it is named as a possible extension: "uncertainty estimates of r could be used to influence γ, giving the residual model more impact in high-confidence regions" (§2). — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- Why a GP (ESANN §1, related work): against the hybrid neural networks of the 1990s, "First, in this paper the analytical model is not considered as being given but is learned from data by symbolic regression. Second, Gaussian Processes are used as residual models, facilitating the model selection as there is no need to empirically decide on appropriate neural network architectures". — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- Experiment (ESANN §3): SARCOS inverse dynamics, 21 inputs, "44484 training examples and 4449 test examples", real robot data with no added noise; 4,000 points chosen by k-means serve as the GP's training set or subset, 10 repetitions. The Eureqa formula (Eq. 4) has 11 terms, linear and pairwise products. Test error as standardised mean squared error (Table 1): rigid-body model 0.104, linear regression 0.075, MARS 0.059, GUIDE 0.033, Eureqa 0.062, GP 0.0183 ± 0.0006, subset-of-regressors GP 0.0111 ± 0.0003, Eureqa plus residual GP 0.0222 (γ = 5), 0.0132 (γ = 10), 0.0109 (γ = 15), 0.0099 (γ = ∞), each ± 0.0001–0.0002. The limits are chosen by hand from the output range [−108.5, 107.7]. — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- The author's own reading (ESANN §3.2): the unlimited combination "yields the best accuracy, which is even slightly higher than that of the pure GP and SR models. However, in terms of safety nothing would be gained as it is not possible to fully verify the residual SR model". — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- Springer chapter (abstract only, as summarised on the publisher's listing; full text closed): it reviews interpretable classification and regression (MARS, tree methods, symbolic regression "based on genetic algorithms") and then "proposes combining a symbolic regression model with a Gaussian Process, which improves accuracy and gives error bounds relative to the verified symbolic model". Its reference list includes Rasmussen & Williams and Schmidt & Lipson. The ESANN paper cites the chapter for the MARS model of the same SARCOS problem. — [Springer Professional listing](https://www.springerprofessional.de/safe-and-interpretable-machine-learning-a-methodological-review/3946354); [Crossref reference list](https://api.crossref.org/works/10.1007/978-3-642-32378-2_8)
- Neurocomputing 2014 (not read; abstract as paraphrased by a web search, and an automatic one-line summary): "A new semi-parametric approach is proposed for providing an interpretable model with improved accuracy by combining a symbolic regression model with a residual Gaussian Process"; the search summary of the abstract adds that, compared with semi-parametric Gaussian processes, the symbolic part is learned separately, which allows a wider range of symbolic forms than a fixed set of basis functions. Its reference list adds Duvenaud et al. "Additive Gaussian processes", Bengio et al. on local kernel machines, and Narendra & Parthasarathy. — [Semantic Scholar record](https://api.semanticscholar.org/graph/v1/paper/DOI:10.1016/j.neucom.2013.11.042?fields=title,tldr); [doi:10.1016/j.neucom.2013.11.042](https://doi.org/10.1016/j.neucom.2013.11.042); [Crossref reference list](https://api.crossref.org/works/10.1016/j.neucom.2013.11.042)

### Inferences

- The GP here is a regression smoother added after the fact. Its hyperparameters are tuned once (presumably by marginal likelihood, as in the Rasmussen & Williams code the paper cites; the paper does not say), but no marginal likelihood is compared across symbolic structures, and the formula is never revised in the light of the GP.
- If the Neurocomputing abstract is as paraphrased, the author states the contrast himself: in "semi-parametric Gaussian processes" (a GP with explicit basis functions, fitted jointly) the symbolic part is a fixed basis, and his method differs by learning the symbolic part separately. So the paper positions itself away from joint inference, which is where GP holes sit.
- The motive is safety and verification (a bound on the deviation from a verified formula), not discovery of the formula. The form "formula plus bounded nonparametric remainder" is nevertheless published since 2013 and should be cited for the idea of keeping a remainder.

### Gaps

- The Springer chapter and the Neurocomputing paper were not read in full. The Neurocomputing paper is six pages with 14 references and its first reference is the ESANN paper, so it is likely an extended version of it (inference); whether it adds a joint fit, a different kernel (it cites additive GPs) or other data is not known.
- The objective used to optimise the 23 GP hyperparameters is not stated in the ESANN text.

## 3. NestyNet I, II and IV, and Part III §6: what does each part do; does any use a GP, a marginal likelihood or another Bayesian score; can unresolved neural parts stay in the reported answer; how few points; and what exactly does Part III §6 say?

### Takeaway

The series has four parts on arXiv, all by the same five authors, all dated August 2026. No part uses a Gaussian process in its method; Part I compares against one and sets it aside for cost and composability. A Laplace-approximated marginal likelihood does appear, but only to set the regularisation of the neural surrogate (Part I) and to weight surrogate capacities (Part II); expressions are never scored by it. One result in Part III does leave a nonparametric function in the reported answer, with a posterior on its slope: the SPARC example, where the inner coordinate is symbolic and the outer law `F` is reported as nonparametric because held-out data cannot separate the candidate formulas. Part III's symmetry layer is demonstrated with exact gradients, is said to hold only while gradient errors stay near 10⁻³, and abstains on 945 real points with 0.12 dex scatter.

### Cited Findings

#### The series

- An arXiv search for "NestyNet" on 28 November 2026 returns exactly four entries, all by Rodrigo Ibata, Wassim Tenachi, Foivos Diakogiannis, Neil Ibata and Anirudh Shankar, category astro-ph.IM, all at v2 of 25 August 2026: Part I, arXiv:2608.05862 (6 August 2026, 25 pages); Part II, arXiv:2608.06274 (6 August 2026, 16 pages); Part III, arXiv:2608.21051 (21 August 2026, 24 pages); Part IV, arXiv:2608.21491 (21 August 2026, 20 pages). — [arXiv API listing](https://export.arxiv.org/api/query?search_query=all:NestyNet&max_results=30)
- Division of labour, Part I §1: "The present work establishes the deterministic NestyNet substrate. In … Paper II we construct its coherent function-space posterior, while in … Paper III and … Paper IV we use its analytic differential structure for symbolic-regression and differential-equation discovery." A further "SPLA theory paper" on the linear algebra is cited, and Part II says "Later papers in this series attach the sister to learned world models" (§8). — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862); [arXiv:2608.06274](https://arxiv.org/abs/2608.06274)

#### Part I: "Physics Functions Are Hard to Fit with Neural Networks: A Framework for Accurate Surrogates and Analytic Derivatives"

- What it is: "a coupled model-and-optimizer framework". The model is "a shallow, single-hidden-layer segmented neural network", `f_o(x) = Σ_s a_os σ(Σ_j K_osj x_j + b_os)` with `σ(z) = log(1 + e^z)` (softplus), optionally stacked in two layers; gradients, Hessians, Laplacians and antiderivatives are in closed form (§2.1, §3). The optimiser is Levenberg–Marquardt with a preconditioner built on the segment structure (§4, §5). — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862)
- Bayesian element (§5.3, "Evidence-Based Spatial Regularization"): penalty strengths on locally coherent residual patterns and per-segment Gaussian shrinkage strengths "are set by maximizing the Bayesian evidence". "To score the regularization strengths η_f and α_s … we use the Laplace approximation to the marginal likelihood ('Bayesian evidence'), following the evidence framework of MacKay"; Eq. 32 gives `log p(y) ≈ −½ zᵀQz − ½ (θ−μ)ᵀP(θ−μ) + ½ log|Q| + ½ log|P| − ½ log|H|`. "the inner loop remains an LM solve of the augmented least-squares objective, while the outer evidence loop scores the regularization strengths". — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862)
- Gaussian processes appear once, as a baseline the authors chose not to use (§8.3, "Choice of baselines"): "On a smooth three-dimensional case such as AI Feynman problem #29, a well-tuned Gaussian process (GP) and the dual-layer segmented surrogate, each fitted to the same 5×10³ points, reach essentially the same accuracy: relative errors of 0.03%, 0.25%, and 1.2% (GP) versus 0.04%, 0.31%, and 1.1% (NestyNet) on values, gradients, and second derivatives, so the segmented surrogate matches the strongest classical interpolant even in the regime that most favors it." The stated reasons against the GP: "a dense kernel solve that is O(N²) in memory and O(N³) in time", and "kernel and spline interpolants are not designed to be composed (stacked, embedded in PDE residuals or implicit solves, tied across vector-valued outputs, and optimized end-to-end by a second-order method)". — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862)
- Data sizes: "All derivative comparisons use 1.5×10⁴ training points and 5×10³ validation points" on the 120 AI Feynman targets, noiseless (§8.3); optimiser and speed tests at 5×10³ and 2×10³ points (§8.1, §8.5); a stellar-dynamics application on 2.5×10⁴ to 4×10⁵ stars (§9). Headline: median error ratios against Adam-trained networks of about 2,100 for values, 1,400 for first and 780 for second derivatives (abstract). — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862)
- A result of use to any surrogate-based structure test (§8.4, Proposition 1): `‖∇e‖² ≤ ‖e‖ · |e|_H²` for the fit error `e`, and across 360 fits "356 lie within the factor-two band" of equality, so "the gradient error is the geometric mean of the value error and the curvature error"; "the law supplies an inexpensive a posteriori upper bound on the gradient error that requires no derivative data". — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862)
- No symbolic regression in Part I; no symbolic or partly symbolic answer is produced. — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862)

#### Part II: "Coherent Function-Space Posteriors from Scientific Neural Surrogates (or How to Avoid Expensive MCMC)"

- What it is, in the authors' shorthand: "linearized Laplace, pushed to function space, followed by a singular value decomposition" (§1.1). With `J_m` the Jacobian of the whitened predictions, `P` the prior precision and `H = J_mᵀJ_m + P`, the posterior covariance of the fitted function is `C_post(X, X′) = J_f,X H⁻¹ J_f,X′ᵀ` (Eq. 9); its leading singular functions `ψ_k` give the "sister" model `f(x, ζ) = f̂(x) + Σ_k s_k ζ_k ψ_k(x)` with independent Gaussian coefficients (Eq. 26). Derived quantities, including derivatives, are computed on each draw. — [arXiv:2608.06274](https://arxiv.org/abs/2608.06274)
- It is a posterior around one fitted network, not a prior over functions: "The result is conditional on the fit's declared choices (architecture, hyperparameters, active set, and optimization branch)" (abstract); "It does not represent disconnected basins, model discrepancy, or non-Gaussian response along weakly constrained directions" (§8). Antecedents are named: "Reading a Gauss–Newton solve as Bayesian inference in a locally linearized model is the linearized Laplace approximation. It has been classical since MacKay" (§1.1). The only Gaussian-process reference is a citation of Khan et al., "Approximate inference turns deep networks into Gaussian processes", in that sentence's citation list. — [arXiv:2608.06274](https://arxiv.org/abs/2608.06274)
- Marginal likelihood (§6.5, "Evidence priors and capacity averaging"): a grid of 21 surrogate configurations (segment count `S ∈ {80, 100, 120}` times prior strength `α`), "the Laplace evidence of each fixed-α fit as its model score", weights `w_j ∝ p_Lap(D | S_j, α_j) π_j`, and a mixture posterior (Eq. 25). "This is nevertheless a finite empirical-Bayes structural audit, not a claim to integrate over all architectures or hyperparameters." The models compared are network sizes and prior strengths, not expressions. — [arXiv:2608.06274](https://arxiv.org/abs/2608.06274)
- Data sizes: the validation case is "N = 50 mock velocities" of a rotation curve with heteroscedastic Gaussian errors `σ_i = 0.012 + 0.010 (r_i/4R_d)`, fitted by "a six-segment scalar single-layer model with P = 18 parameters"; over 20 mock realisations the 68% intervals cover the truth in 14 of 20 cases (spline reference: 16 of 20) (§5.1–5.2). The main case fits 800 parameters to binned counts of 5×10⁵ stars; four modes carry 99% of the posterior variance of the force (§6). — [arXiv:2608.06274](https://arxiv.org/abs/2608.06274)
- No symbolic regression in Part II. — [arXiv:2608.06274](https://arxiv.org/abs/2608.06274)

#### Part III §6, "Generalized Symmetries": the text

- Opening (§6): "The coordinate families of §4 are each the invariant of a one-parameter point symmetry of the target. Monomials arise from scalings, affine coordinates from translations, radii from rotations, and their centered forms from affine conjugates. We have therefore implemented a generalized-symmetry (GS) layer in NestyNet-SR that discovers the symmetries themselves, and with them the reduced coordinates. The layer recovers the Stage A detector families (monomial, affine, radial, indefinite quadratic, difference-product, and centered coordinates) from one operator, replacing a catalog of special cases by geometry." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The vector field (§6.1, Eq. 7): "Consider the graph y = f(x) of the surrogate, with x ∈ ℝⁿ, and the affine vector field `V = (A x + b)·∇_x + (α + β y) ∂_y`, with an unknown input action (A, b) and an unknown output action (α, β)." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The linear condition (§6.1, Eq. 8): "The field V generates a one-parameter family of transformations that maps the graph of f to itself precisely when V is tangent to the graph, which is the determining equation of Lie symmetry analysis [Olver 1993], `∇f(x)·(A x + b) − α − β f(x) = 0`." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- How it is solved (§6.1): "The essential observation is that Eq. (8) is linear in all n² + n + 2 unknowns jointly, so every sampled point contributes one row of a design matrix, and the full Lie algebra of affine symmetries of the target is the nullspace of the stacked system, obtained by a single SVD. The analytic NestyNet gradients make these rows accurate enough for the construction to be practical." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- Safeguards (§6.1): "The scientific object is the nullspace subspace, not any individual basis vector (when the nullity exceeds one, an SVD basis is arbitrary), so all downstream logic operates on the subspace projector, the rank of the pointwise distribution it spans, held-out residuals, and bootstrap principal angles. A candidate algebra must further pass certificates (closure of the Lie bracket including the output action, a stable distribution rank, a consistent quotient dimension) before any coordinate is built from it." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The structure derived (§6.1, Eq. 9): "A certified algebra is then compiled into a reduction plan: invariant coordinates z(x) spanning the quotient, an orbit coordinate s, and an output normal form. For an accepted generator with V f = α + β f, the target takes the form `f = −α/β + e^{βs} H(z)` (β ≠ 0), `f = α s + H(z)` (β = 0), so a promoted reduction proposes the inner coordinates and the outer structure simultaneously." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- Acceptance (§6.1): "Promotion itself is gated, so that a reduction enters the active Stage A slate only if it survives a complexity-penalized comparison against the unreduced expression at matched held-out accuracy, and under the default policy it only augments the baseline proposals." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- Other charts (§6.2): "Solving Eq. (8) in the chart u_i = log x_i (with chain-ruled gradients) turns scalings into translations, so monomial coordinates ∏ x_i^{a_i} appear as linear invariant covectors whose components are snapped to small rationals and revalidated against the determining residual. The chart u_i = 1/x_i similarly exposes coordinates linear in reciprocals, Σ c_i/x_i." A further step finds per-axis warps for `f = g(Σ c_i φ_i(x_i))`: "The certificate is the normalized off-diagonal Hessian ratio R_ij = (∂_i ∂_j f)/(∂_i f ∂_j f), which equals g″/g′² for every pair (i, j) whenever such a warp exists". — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- What the layer adds beyond the fixed detectors (§6.3): "The GS layer solves for arbitrary real generators". For `sin(√2 x₀ − x₁)` "the integer-affine detector proposes its best integer ray with a coordinate-angle residual of 0.17, while the GS affine solve recovers the oblique covector to 5×10⁻⁷. On a generic target with no symmetry, the solver correctly proposes no generator at any tested noise level." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- Use downstream (§6.4): the layer "discovers the coordinate from the gradient geometry of the target and seeds it into the search as a carrier, after which the ordinary outer-map battery of §5.1 fits g(z) in closed form". "The seed closes problems of the form y = g(z(x)). When a prefactor multiplies the coordinate … the coordinate alone does not suffice." — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)

#### Part III: statements on gradient accuracy and number of points

- Gradient accuracy, three statements. §6.1: "The analytic NestyNet gradients make these rows accurate enough for the construction to be practical." §6.2: "On trained surrogates, whose gradients carry relative errors of order 10⁻³, the global nullspace solve can lose bracket closure. The layer therefore also composes coordinates from pairwise witnesses, one-dimensional scaling, translation, rotation, and Lorentz-boost tests that remain reliable at surrogate noise levels, chaining accepted pairs into global monomial, linear, radial, and indefinite-quadratic coordinates … and a noise-calibrated tier of acceptance statistics lets certified reductions be promoted from trained surrogates." §11.3: "symmetry discovery inherits the surrogate's derivative quality, certifying only while gradients are accurate to ∼10⁻³"; the "measured gradient-noise ladder" behind that number is "distributed with the code as a worked example", not printed. — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The section's own demonstrations use exact values and exact gradients, not a trained surrogate. Table 2 is "in oracle mode (exact function values, no surrogate, §11.2)", 2,500 mutation iterations, single seed. In §11.2: "The search receives exact function values and dimensional metadata (512 fit points and a 2 048-point search probe)"; "FSS evaluates exact target gradients solely to propose GS coordinates as carrier seeds"; "The result is accordingly an exact-oracle-gradient numerical ablation." Result there: 88 of the 115 equations with at most six variables (76.5%). — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The full-pipeline benchmark (§11.1): "2×10³ training and 2×10³ validation points (instead of using the 10⁵ points allowed by the benchmark) drawn uniformly from the published domain, with no added noise"; 120 of 120 recovered; this run has the factorized search disabled, the symmetry layer is drawn as "optional" in Figure 1, and Table 3 does not list it. With noise `σ/σ_y` of 10⁻³, 10⁻², 10⁻¹: 105, 94, 56 solved (heuristic acceptance), 103, 91, 54 (statistical selection), 110, 89, 62 (committee, which uses 8 + 11 further slices of 2,000 + 2,000 points and "a separate sealed audit partition of 20 000 rows") (Table 4). — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- On real, noisy data the determining operator abstains (§11.4, Figure 6). On the SPARC sample of "48 galaxies with 945 points", a control that keeps the real inputs and plants a known law finds "its smallest singular value falling a factor of 50 below the rest of the spectrum (certification requires a factor of 10)", "while 0.12 dex of scatter, row-independent or galaxy-correlated, closes that separation and the operator abstains on data that contain the carrier by construction". Figure 6d: "the gradient certificate succeeds only in the clean limit; the collapse recovers it from real data". — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- Second derivatives (§2.2): "When Hessian elements carry ∼10% relative error, testing whether ∂²f/∂x_i∂x_j ≈ 0 becomes unreliable". Defaults: mixed-second-derivative tolerance 10⁻³, rank-one gate `σ₂/σ₁ ≤ 0.1` (Table 3). — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- No sentence in Part III gives a minimum number of points for §6. — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)

#### Part III: can an unresolved part stay in the answer, and is any score Bayesian?

- The stated design is a closed form: neural atoms are the state "throughout Stage A and in the unresolved branches of Stage B"; "The final output is a human-readable analytical expression" (§3). On the Feynman benchmark success is algebraic identity with the target (§11.1). — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The SPARC example reports a nonparametric outer function (§11.4). Sought structure (Eq. 21): `z = g_gas + Υ_d g_disk`, `g_obs = F(z)`. "The carrier is identified by the class-shared collapse, the multi-dataset structure of §7.10 specialized to Eq. (21), with F nonparametric, and each galaxy being a separate experiment." Profiling over the carrier direction with whole-galaxy bootstraps gives `Υ_d = 0.56 ± 0.14`. Five closed forms for `F` "all land within 0.106–0.116 dex of error-weighted held-out scatter, against a galaxy-bootstrap uncertainty of 0.022 dex. None improves on the nonparametric collapse law itself, 0.118 dex on the same metric, by more than that uncertainty." "the complexity–accuracy Pareto front is flat within that uncertainty: no candidate can be isolated, and added structure yields no accuracy improvement on held-out samples. We therefore report the outer law as a family … and promote no unique interpolation function. Instead, what the data do identify is delivered through the statistical layer of Paper II (the 'sister' model). Conditional on the discovered carrier … coherent sister model draws of the law and its derivative … give the posterior of the local slope s(z) = d log F/d log z on the domain where its certificates hold." Data: 34 discovery galaxies and 14 held out; the one-dimensional law predicts held-out galaxies at 0.13 dex against 0.65 dex for an unrestricted two-input surrogate. — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- The abstract lists this among the results: "a calibrated symmetry abstention, and a posterior for the local slope of the law". — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- Scores in Part III are losses, not likelihoods. Factorized search: `L(s) = min over M_θ ∈ M, h ∈ H of ‖y − M_θ(s(x)) − h(x)‖² + λ C(s, M_θ, h)`; "In the configuration used throughout this paper λ is zero and parsimony acts lexicographically" (§5). Rewrites: accepted "when the loss improves beyond a tolerance" (§7.4). Statistical mode: one-sided simultaneous 95% bounds on paired held-out loss differences from a multiplier bootstrap, with a complexity vector that includes "numerical-constant description length" (§7.5). The only "evidence" in the pipeline is inside the surrogate fit: "canonical initialization and segment-prior (evidence) mode on" (Table 3), which is Part I's Laplace evidence for regularisation strengths. — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)
- A naming collision: Part III uses "hole" for a different thing. "A separate hole-search mechanism maintains a frontier of partial repair opportunities" (§5.3), and the search's action list includes "inverse-repair, and hole-repair routes" (Algorithm 1). These are places in a near-miss expression to be refilled by local symbolic search. — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)

#### Part IV: "Laws Chosen by Nothing in Advance"

- What it is: discovery of differential equations from the surrogate's analytic derivatives, by two routes (§2). First, sparse regression in the manner of SINDy: `L_m[u] + Σ_k c_mk φ_k(x, u, ∂u, ∂²u) = 0` with a library evaluated from "a frozen neural surrogate", selected by sequential thresholded least squares (§4.1–4.2). Second, "operator-factorized search" over balances `L_m[u] + Σ_j g_j(z_j) φ_j = 0`, "in which each term is a product of a few typed factors, namely a fixed carrier φ … multiplied by a discovered coefficient g(z), a univariate function of a single argument z"; `g` is fitted from "the coefficient-function families … e.g. affine, power, exponential, logarithm, and rational"; candidates are ranked by forward integration: "integration success, domain safety, integration/probe error, then size" (§4.3, Algorithm 1). — [arXiv:2608.21491](https://arxiv.org/abs/2608.21491)
- Symmetry layer for equations (§6.1–6.2): for a recovered law `u_x = f(x, u)`, restricting the generator to the affine family "turns Eq. (9) into a linear determining system whose nullspace, computed by SVD and snapped to integer generators, is the candidate's certified algebra"; a supported generator gives coordinates `(r, s)` in which "the reduced equation is univariate, ds/dr = G(r), and we fit G with the same mapping families". The symmetry is used to choose between candidates that fit equally, to make library terms, and to integrate the law. — [arXiv:2608.21491](https://arxiv.org/abs/2608.21491)
- No GP, no marginal likelihood and no Bayesian score for laws: a search of the body for "Gaussian process", "posterior", "Bayes", "likelihood" and "description length" finds nothing; "prior" occurs only for the dimensional ("unit") prior that prunes terms whose coefficient would need an undeclared constant (§4.9, §7.4), and once in the remark that a symmetry is "never imposed as a prior" (§6). — [arXiv:2608.21491](https://arxiv.org/abs/2608.21491)
- No neural part in the answer: the paper contrasts itself with Neural ODEs and Hamiltonian networks, where "the learned object remains a neural network rather than an explicit law" (§1); results are scored PASS/PARTIAL/FAIL on explicit laws. The one stated abstention concerns integration, not the law: when no solvable algebra is found "it reports that no closed form was found rather than forcing a spurious one" (§6.3). — [arXiv:2608.21491](https://arxiv.org/abs/2608.21491)
- Experiments: 83 cases (57 real scalar ODEs, 26 complex-valued systems), each scored "on two sealed test trajectories"; sparse regression alone passes 39 of 57 scalar cases, 52 with the second route; complex cases 23 pass, 3 partial (§7.1–7.2, Table 2). Maxwell's equations with decoy Laplacian terms: with a trained surrogate "clean rejection holds to 10⁻⁶ relative noise and collapses by 10⁻⁵" without units, and to 10⁻⁴ with the unit prior; "A single noise realization per level is used" (§7.4, Table 1). Real data: "30 years of daily ephemerides of 308 main-belt asteroids", split 246/31/31, recovering `r̈ = k_d/r³ − μ/r²` and `k_d = ℓ_d²` (§7.5). The number of points per trajectory in the 83-case benchmark is not given in the text read. — [arXiv:2608.21491](https://arxiv.org/abs/2608.21491)

### Inferences

- (Inference, comparing Parts I and III.) Part I's GP comparison puts numbers on the question the earlier notes left open: at 5,000 noiseless points in three dimensions a tuned GP has relative gradient error 0.25% and second-derivative error 1.2%, about the same as the neural surrogate. Part III says the global symmetry solve certifies only near 10⁻³ gradient accuracy. So even with 5,000 clean points a GP sits at the edge of what the authors' global nullspace test tolerates, and at about 100 noisy points a test of that kind on posterior-mean gradients should not be expected to certify anything. This supports treating the linear relation as a proposal generator whose proposals are then judged by the evidence, which is what GP holes does, and it is consistent with Part III's own fallback to pairwise tests and with its abstention on SPARC.
- (Inference.) Part III's forms in Eq. 9 are instances of the GP-holes model class: `e^{βs}·H(z) − α/β` is `a(x)·H(u(x)) + const`, and `α s + H(z)` is `w·b(x) + H(u(x))`. Part IV's balances `Σ_j g_j(z_j) φ_j` have the same shape, a known factor times an unknown univariate function of a chosen argument, with `g` drawn from a short list of parametric families. In neither paper is `H` or `g` given a prior and integrated out.
- (Inference.) The SPARC example is the nearest thing in the series to "a hole remains in the final answer". It has the ingredients in outline: a symbolic inner coordinate with one fitted parameter, an outer function kept nonparametric, a decision not to replace it because no formula earns its complexity, and a posterior on a property of the nonparametric part. The mechanisms differ in each place: the coordinate is chosen by collapse scatter and held-out error with galaxy bootstraps, not by a marginal likelihood; the decision to keep `F` rests on held-out scatter against a bootstrap uncertainty, not on evidence with a complexity penalty; the posterior is a linearised Laplace posterior around one fitted network, conditional on its architecture, not a GP posterior; and it is a one-off analysis of one dataset (945 points, 2 inputs, hand-specified structure in Eq. 21), not a step of a general search. The earlier notes' statement that the method "declines to answer instead" is too strong for this example and should be corrected.
- (Inference.) "Has been run on how few points": for symbolic regression with a trained surrogate, 945 real points (SPARC, where the symmetry layer abstained and the result is partly nonparametric) and otherwise 2,000 + 2,000 clean points; 512 fit points only with exact function values and exact gradients. The 50-point case in Part II is a posterior for a one-dimensional curve with no symbolic step. Nothing in the series shows symbolic recovery from about 100 noisy points.
- (Inference.) The series shows that its authors considered a GP as the surrogate and rejected it for reasons (cubic cost at 10⁵ points, composition with second-order optimisation) that do not bind at about 100 points. That leaves the small-data, GP-based variant unoccupied by them, and gives a citable statement that GP and neural surrogate are equally accurate where both apply.

- Whether the symmetry layer was active in the 120-of-120 run is not stated in the text; Table 3 does not list it.
- Part IV's per-case data sizes and noise for the 83-case benchmark were not found in the main text or the appendix table as extracted.
- The series is unreviewed (arXiv preprints of August 2026); numbers are the authors'. The "SPLA theory paper" and the announced later parts were not found on arXiv under the name NestyNet.

## 4. Does any of the three change the conclusion that no published method marginalises a GP for the unknown part of an expression and uses the evidence to score partial expressions in a search?

### Takeaway

No, on what could be read; with one reservation and one correction. The reservation: the Cohrs et al. paper itself was not opened, and the conclusion for it rests on its abstract and on the authors' repository. The correction: the claim "a hole can remain in the final answer" has a closer published precedent than the earlier notes recorded, in NestyNet III's SPARC example, though by a held-out test and a network posterior, not by GP evidence.

### Cited Findings

- Cohrs et al.: the proposed method is described by its authors as "hybrid equation discovery" aimed at "fully interpretable data-driven models" (abstract), and their framework's learned component is "neural networks or symbolic regression", the latter by the Bayesian machine scientist with "Full posterior over equations and parameters" (README). No GP and no marginalised function appear in any source reached. — [ICLR page](https://www.iclr.cc/virtual/2024/21401); [GitHub: KaiHCohrs/semi-param-hybrid-modeling](https://github.com/KaiHCohrs/semi-param-hybrid-modeling)
- Otte: a GP regression "learned on the residuals" of a formula that was fixed beforehand by training error, clipped to ±γ; the GP's uncertainty is not used (§1, §2). — [ESANN 2013 PDF](https://www.esann.org/sites/default/files/proceedings/legacy/es2013-3.pdf)
- NestyNet: the surrogate is a neural network; a GP is mentioned only as a baseline of equal accuracy (Part I §8.3); marginal likelihood is used only for the surrogate's regularisation and capacity (Part I §5.3, Part II §6.5); expressions are compared by fitted or held-out loss (Part III §5, §7.4, §7.5) or by forward integration (Part IV §4.3). — [arXiv:2608.05862](https://arxiv.org/abs/2608.05862); [arXiv:2608.06274](https://arxiv.org/abs/2608.06274); [arXiv:2608.21051](https://arxiv.org/abs/2608.21051); [arXiv:2608.21491](https://arxiv.org/abs/2608.21491)
- NestyNet III reports one partly nonparametric answer with a posterior: "We therefore report the outer law as a family … and promote no unique interpolation function", with "the posterior of the local slope" from Part II's construction (§11.4). — [arXiv:2608.21051](https://arxiv.org/abs/2608.21051)

### Inferences

How close each is to GP holes, feature by feature (my assessment):

| Feature of GP holes | Cohrs et al. 2024 (from abstract and repository) | Otte 2013/2014 | NestyNet I–IV |
|---|---|---|---|
| Unknown part of an expression held as a function with a GP prior | No. Unknown part is a neural network (baseline) or a symbolic expression (proposed) | A GP, but on the residual of a finished formula | No. A neural network; GP named only as an equally accurate baseline |
| That function integrated out exactly | No | No. Predictive mean only | No. Linearised Laplace posterior around one fit (Part II) |
| Evidence used to score partial expressions | No partial expressions with a function in them; complete expressions scored by description length (BIC plus prior) | No. Formula by training error, GP afterwards | No. Losses, held-out loss bounds, forward integration. Laplace evidence only for the surrogate's regularisation |
| Search from "all nonparametric" towards structure | No. Search over expressions for the unknown part, known part fixed | No search over the split | Yes in outline (Part III: surrogate, then decomposition into atoms, then closed forms), by derivative tests and loss |
| Known part times or plus unknown function, `a(x)·H(u(x)) + w·b(x)` | Yes as a problem class (`fp + fa`, `fp * fa`, `fp / fa`), with `fp` given by the user | Additive only, `a(x) + clip(r(x))` | Yes (Part III Eq. 9; Part IV Eq. 3), derived from symmetry or searched |
| Hole may remain in the answer, with error bars | No | Remainder always remains, bounded by hand, no error bars | Once: SPARC example, by held-out test, with a Laplace posterior on the slope |
| About 100 noisy points | Unknown | No (44,484 points) | No (2,000 + 2,000 clean; 945 real points in one example) |

- The combination that defines the method, a GP prior on the unknown function inside an expression, exact marginal likelihood because the function enters linearly, and that evidence with a complexity penalty as the score of each partial expression in a greedy search, is in none of the three.
- What these items do take away from a novelty claim, and should be cited: the partly-known, partly-unknown expression as a problem class with sum, product and quotient forms (Cohrs et al., and hybrid modelling generally); "formula plus nonparametric remainder" (Otte); the forms `e^{βs}H(z)` and `αs + H(z)` from a linear condition on gradients (NestyNet III §6, already in the earlier notes); and reporting a symbolic inner coordinate with a nonparametric outer law and a posterior when the data cannot choose a formula (NestyNet III §11.4, new in these notes).
- A sentence that the evidence here supports: these works either fix the formula and add a nonparametric remainder afterwards, or replace the nonparametric part by symbols using losses and held-out tests; none infers the two jointly under one probabilistic model.
